01 / Introdução

O que é DCL?

DCL (Data Control Language) é a linguagem utilizada para controlar permissões de acesso em bancos de dados.

🔐

Controle de acesso

Define quais usuários podem acessar ou modificar informações.

🛡️

Segurança dos dados

Ajuda a proteger informações contra acessos não autorizados.

💡

Exemplo: um funcionário pode consultar os dados de uma empresa sem ter permissão para apagá-los.

02 / Comando DCL

GRANT — Conceder acesso

O comando GRANT concede permissões a usuários ou funções do banco de dados.

EXEMPLO SQL 
GRANT SELECT
ON clientes
TO enzo;
✅

Resultado: Enzo recebe permissão para consultar a tabela clientes, sem receber, por esse comando, permissão para alterar ou excluir registros.

03 / Comando DCL

REVOKE — Retirar acesso

O comando REVOKE revoga permissões concedidas anteriormente.

EXEMPLO SQL 
REVOKE SELECT
ON clientes
FROM enzo;
🚫

Resultado: a permissão de consulta concedida diretamente a Enzo é revogada. Ele ainda pode possuir acesso recebido por outros meios.

04 / Categorias e permissões

O que podemos controlar?

A DCL administra privilégios para diferentes operações no banco de dados.

👁️ SELECT

Consultar informações.

➕ INSERT

Inserir novos registros.

✏️ UPDATE

Modificar registros existentes.

🗑️ DELETE

Excluir registros.

🔑

Resumo: GRANT concede permissões e REVOKE revoga permissões. Alguns sistemas, como o SQL Server, também possuem DENY para negar acessos explicitamente.
